# Proposal site

A simple “Will you be mine?” page where the **No** button moves away when you try to click it.

## Host on GitHub Pages

1. Create a new repo (e.g. `proposal-site`).
2. Push this folder’s contents to the repo (only `index.html` and this README are needed).
3. In the repo: **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** (or **master**) → folder: **/ (root)** → Save.
4. After a minute or two, the site will be at `https://<username>.github.io/proposal-site/`.

No build step required—just static HTML/CSS/JS.
